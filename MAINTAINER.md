# AdambotsLib - Maintainer Guide

This guide is for team members who maintain and publish the AdambotsLib library.

## Overview

AdambotsLib is published as a vendor dependency that can be used in FRC robot projects. The library is hosted on GitHub Pages at:
- **Maven Repository**: https://adambots-245.github.io/AdambotsLib/maven
- **Vendordep JSON**: https://raw.githubusercontent.com/Adambots-245/AdambotsLib/main/AdambotsLib.json

## Project Structure

```
AdambotsLib/
├── AdambotsLib.json          # Vendordep file (auto-generated)
├── gradle.properties         # Version and publishing configuration
├── build.gradle              # Build configuration with publishing
├── publish-to-maven.sh       # Helper script for publishing
├── maven/                    # Published artifacts (committed to Git)
│   └── com/adambots/lib/AdambotsLib-java/2026.1.0/
├── src/main/java/            # Library source code
└── vendordeps/               # Library dependencies
```

## Building the Library

### 1. Build Locally

To build the library without publishing:

```bash
./gradlew clean build
```

This will:
- Compile the Java code
- Run tests (if any)
- Auto-generate `AdambotsLib.json` with current version
- Create JAR file in `build/libs/`

### 2. Test Locally

To test the library in another project before publishing:

```bash
# Publish to your local Maven cache
./gradlew publishToMavenLocal
```

This installs the library to `~/.m2/repository/com/adambots/lib/AdambotsLib-java/`

Then in your test robot project:
1. Copy `AdambotsLib.json` to the robot project's `vendordeps/` folder
2. Build the robot project - it will use your local version

## Publishing a New Release

### Step 1: Update the Version

Edit `gradle.properties` and update the version number:

```properties
version=2026.1.0  # Change to your new version (e.g., 2026.1.1, 2026.2.0)
```

**Version Scheme:**
- Format: `YEAR.MAJOR.MINOR`
- Example: `2026.1.0` → First release for 2026 season
- Example: `2026.1.1` → Bug fix release
- Example: `2026.2.0` → New features release

### Step 2: Build and Publish

Use the provided helper script:

```bash
./publish-to-maven.sh
```

**Or manually:**

```bash
# Clean and build
./gradlew clean build

# Publish to build/maven directory
./gradlew publish

# Create/update maven directory
mkdir -p maven
cp -r build/maven/* maven/
```

This creates the maven repository structure with:
- `AdambotsLib-java-2026.1.0.jar` - The compiled library
- `AdambotsLib-java-2026.1.0.pom` - Maven metadata
- `AdambotsLib-java-2026.1.0.module` - Gradle module metadata

### Step 3: Verify the Build

Check that the files were created:

```bash
ls -R maven/com/adambots/lib/AdambotsLib-java/
```

Verify `AdambotsLib.json` has the correct version:

```bash
cat AdambotsLib.json
```

### Step 4: Commit to Git

```bash
# Add the changes
git add AdambotsLib.json maven/ gradle.properties

# Commit with a descriptive message
git commit -m "Release AdambotsLib v2026.1.0"

# Tag the release (optional but recommended)
git tag -a v2026.1.0 -m "AdambotsLib version 2026.1.0"

# Push to GitHub
git push origin main
git push origin v2026.1.0
```

### Step 5: Verify GitHub Pages

After pushing, verify that GitHub Pages is serving the files:

1. Wait 1-2 minutes for GitHub Pages to rebuild
2. Check the Maven repository:
   ```
   https://adambots-245.github.io/AdambotsLib/maven/com/adambots/lib/AdambotsLib-java/2026.1.0/
   ```
3. Check the vendordep JSON:
   ```
   https://raw.githubusercontent.com/Adambots-245/AdambotsLib/main/AdambotsLib.json
   ```

## Configuration Files

### gradle.properties

```properties
# Library Information
group=com.adambots.lib
version=2026.1.0
description=AdambotsLib - Reusable components library for FRC Team 245

# Publishing Configuration
publishUrl=https://adambots-245.github.io/AdambotsLib/maven
```

**Key Fields:**
- `group`: Maven group ID (don't change)
- `version`: Current library version (update for releases)

## Troubleshooting

### Problem: AdambotsLib.json not updating

**Solution**: The file is auto-generated on every build. If it's not updating:
```bash
./gradlew clean generateVendordep
```

### Problem: Maven artifacts not appearing on GitHub Pages

**Solution**:
1. Verify GitHub Pages is enabled: Settings → Pages → Source = "Deploy from main branch"
2. Check that the `maven/` directory is committed to Git
3. Wait 1-2 minutes for GitHub Pages to rebuild
4. Clear your browser cache

### Problem: Version mismatch

**Solution**: Always update the version in `gradle.properties` and rebuild:
```bash
# 1. Edit gradle.properties
# 2. Rebuild
./gradlew clean build
```

### Problem: Testing changes locally

**Solution**: Use `publishToMavenLocal` to test without publishing:
```bash
./gradlew publishToMavenLocal
# Then copy AdambotsLib.json to your test project's vendordeps/
```

## Important Notes

1. **Always regenerate** `AdambotsLib.json` after version changes (happens automatically on build)
2. **Commit the maven/ directory** - it needs to be in Git for GitHub Pages
3. **Use semantic versioning** - YEAR.MAJOR.MINOR format
4. **Test locally first** - Use `publishToMavenLocal` before publishing
5. **Tag releases** - Use Git tags for version tracking

## GitHub Pages Setup (One-Time)

If GitHub Pages is not yet configured:

1. Go to repository Settings
2. Click "Pages" in the sidebar
3. Under "Source":
   - Branch: `main`
   - Folder: `/ (root)`
4. Click "Save"

The library will be available at:
`https://adambots-245.github.io/AdambotsLib/maven`
